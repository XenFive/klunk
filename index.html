Klunk - Log Viewer (beta)

A free, quick, no-fuss desktop log viewer for multiple sources — with merging, SQL-like filtering and analysis.

Key Features

Multiple Data Sources

Local files, databases, Kubernetes pods, SFTP, HTTP get/post URLs. Opens logs directly inside .zip, .gz, .tar and .tar.gz archives, locally or over SFTP. Search Files searches through files and can import just the matching files or rows.

Log Merging

Combine files into one chronological stream with color-coded sources — or keep them separate and use Synch All to scroll every open log to the same time.

Advanced Filtering

SQL-like syntax — LIKE, =, AND, OR, nested groups.

Bookmarks

Pin important rows with multicolor bookmarks, comments, and time markers — then filter down to just what you've flagged, plus Bookmark time to mark the same moment across every open log.

Customisable Patterns

Regex-based pattern engine supports Log4j, Logback, CSV, JSON, XML, key-value and custom formats. Formats are auto-detected, and a generator builds new patterns from a sample line.

Adaptive Storage

Smaller logs stay fully in memory for speed; larger ones switch to SQLite-backed paging and handle millions of rows. The switch-over threshold is configurable in Settings.

Live Tailing

Real-time monitoring with automatic file-rotation detection.

Session Persistence

Saves and restores opened files, filters, window positions, and bookmarks.

Visual Time Slider

Dual-thumb vertical slider with error/warning markers and live viewport tracking.

Interactive UI

Dockable tabs, in-text search with highlighting, multicolor bookmarks, timestamp timezone conversion, light/dark theme, customizable table font/colors.

Log Analysis

Error/warning reports and charts with best-effort redaction of sensitive data (includes custom find/replace overrides) before anything is copied or exported. (useful for AI prompting)

Compare

Side-by-side diff of pasted text or log rows with changed characters highlighted. Also compares lists ignoring order, and the gaps between timestamps.

Klunk is a JavaFX desktop application, but it's self-contained — the archive bundles its own Java runtime, so there's nothing else to install. It is free to use under a proprietary license — see the Terms of Use. New here? Start with the User Guide.
