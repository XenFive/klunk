Klunk - Log Viewer (beta)

A free, quick, no-fuss desktop log viewer for multiple sources — with merging, SQL-like filtering and analysis.

⬇ Download

Windows macOS Linux x64 Linux ARM64

Current version: v0.9.86 · (this beta version is valid until 4/15/2027)

Free to use · Available for Linux, Windows and macOS (macOS version currently untested)

Key Features

📂
Multiple Data Sources

Local files, databases, Kubernetes pods, SFTP, HTTP get/post URLs.

🔀
Log Merging

Combine files into one chronological stream with color-coded sources.

🔍
Advanced Filtering

SQL-like syntax — LIKE, =, AND, OR, nested groups.

🔖
Bookmarks

Pin important rows with multicolor bookmarks, comments, and time markers — then filter down to just what you've flagged.

⏱
Visual Time Slider

Dual-thumb vertical slider with error/warning markers and live viewport tracking.

🗄
Data Virtualization

Handles millions of rows via SQLite-backed paging.

📡
Live Tailing

Real-time monitoring with automatic file-rotation detection.

💾
Session Persistence

Saves and restores opened files, filters, window positions, and bookmarks.

🧩
Customisable Patterns

Regex-based pattern engine supports Log4j, Logback, CSV, JSON, XML, key-value and custom formats.

🎨
Interactive UI

Dockable tabs, in-text search with highlighting, multicolor bookmarks, timestamp timezone conversion, light/dark theme.

📊
Log Analysis

Error/warning reports and charts with best-effort redaction of sensitive data (includes custom find/replace overrides) before anything is copied or exported. (useful for AI prompting)

⚖
Compare

Side-by-side diff of pasted text or log rows with changed characters highlighted. Also compares lists ignoring order, and the gaps between timestamps.

Klunk is a JavaFX desktop application, but it's self-contained — the archive bundles its own Java runtime, so there's nothing else to install. It is free to use under a proprietary license — see the Terms of Use. New here? Start with the User Guide.
