Where Klunk Keeps Its Files

Find the log file, the config file and everything else Klunk saves, on Windows, macOS and Linux.

Quickest way to the log file: click the About button in the main toolbar, then click View Log. Klunk opens its own log in a viewer.

1. The data folder

Klunk keeps almost everything in one folder, its data folder. Where that is depends on how you run Klunk:

PlatformData folder
Windows The folder that contains Klunk.exe
macOS (Klunk.app) ~/Library/Application Support/Klunk
Linux (packaged app) ~/.local/share/Klunk
(or $XDG_DATA_HOME/Klunk if XDG_DATA_HOME is set)
Any platform, run as java -jar The folder that contains the jar

On macOS, ~/Library is hidden in Finder. Use Go → Go to Folder… (Shift+Cmd+G) and paste the path. On Linux, folders starting with . are hidden; press Ctrl+H in most file managers to show them.

What's in it

File or folderWhat it is
logs/klunk.log Klunk's own application log. Older logs are kept beside it as klunk-<date-time>.log.gz. Attach these when you report a problem.
config.properties Your settings, saved datasources, patterns, filter presets and recent files. It only holds what you've changed; everything else uses the built-in defaults.
config.properties.<date-time>.bak Automatic backups of config.properties (the last 4 are kept). To roll back, close Klunk and copy one over config.properties.
session.json The open windows, filters and bookmarks restored on the next launch.
groups/ Saved file groups, one .json file each.
logviewer.db Klunk's working database of loaded log rows. It can grow large and can be deleted safely while Klunk is closed. To keep it elsewhere, add log.database.location=<folder> to config.properties.

2. Keys, in your home folder

Keys are kept in a .logviewer folder in your home folder, not in the data folder:

  • Windows: %USERPROFILE%\.logviewer (for example C:\Users\you\.logviewer)
  • macOS: ~/.logviewer (/Users/you/.logviewer)
  • Linux: ~/.logviewer (/home/you/.logviewer)
FileWhat it is
secret.key Encrypts the passwords, SSH passphrases and kubeconfigs saved in config.properties. If you delete it, or copy config.properties to another computer without it, you'll need to enter those credentials again.
keys/id_rsa, keys/id_rsa.pub The SSH key pair made by Settings → Generate New Key. Give the server the .pub file; never share id_rsa.
secret.key, keys/id_rsa and config.properties together give access to your saved servers. Keep them private and don't attach them to bug reports.

3. Temporary files

Files downloaded over SFTP, extracted from archives, pasted or dropped in, and converted copies go in the system temp folder, named klunk-temp-…. Klunk removes them when it closes, and clears any left behind by a crash on a later start.

  • Windows: %TEMP%
  • macOS: the folder in $TMPDIR
  • Linux: /tmp

4. Moving the data folder

If Klunk is installed somewhere you can't write to (such as Program Files), or you want its data elsewhere, create a text file named launch.properties next to Klunk.exe (or the jar) with one line:

working.dir=D:/KlunkData

Use working.dir=USER_HOME to put the data folder in .logviewer in your home folder. A relative path is taken as relative to the Klunk folder. The change takes effect the next time Klunk starts; copy your existing files across if you want to keep them.

5. Starting fresh

"Starting fresh" means putting Klunk back the way it was when you first installed it, either completely or one part at a time.

This never touches your own log files. Klunk only reads them, and what it deletes here are its own copies and settings.

Close Klunk first, then delete (or rename, so you can undo it) any of these from the data folder. Klunk recreates each one with default values the next time it starts.

RemoveWhat you lose
session.json The windows, filters, bookmarks and time ranges that were open last time. Klunk starts with no logs open.
logviewer.db Nothing permanent. It only holds rows loaded from your logs, and Klunk loads them again from the original files when you reopen them.
config.properties All your settings, plus saved datasources (database, SFTP, Kubernetes), custom log patterns, filter presets and recent files. To undo only recent changes, restore a .bak backup instead.
groups/ Your saved file groups.

Full reset: remove everything in the table above, plus the logs/ folder and the .logviewer folder in your home folder. On macOS and Linux you can simply delete the whole data folder. On Windows don't, because it's also where Klunk.exe lives. A full reset also removes secret.key and any SSH keys Klunk generated, so servers set up to accept that key will refuse it until you add the new one.
